# 연필 커서 6종 (크로마키 배경)

쓰는 곳: 종이 위에서 마우스 대신 따라다니는 연필 커서 (지금은 코드 그림). 받으면 단색 배경을 빼서 투명 PNG로 만들어 연결함

## 공통
- 1:1, 1024×1024. 연필은 대각선(심 끝이 왼쪽 아래, 약 40°), 그림자·책상 없이 단색 배경만
- 배경: 크로마키 초록 #00FF00 — 단, 초록 연필(제법 좋은 연필)만 마젠타 #FF00FF (연필 색과 겹치지 않게)
- 참고 이미지: 상점 아이콘에 쓴 그 연필 사진을 함께 첨부하고 "이 연필과 똑같이, 배경만 단색으로" 라고 덧붙이면 생김새가 맞음
- 저장 이름: `assets/cursor_0~5.png`
